# Cài bản hiện tại

Đọc [FOR-CODEX](../FOR-CODEX.md) để tải ZIP ghim commit/SHA256 và [setup duy nhất](codex-video-captions/references/setup-and-install.md). CLI hiện tại: --skills-dir hoặc --target-dir, --check-only, và --upgrade --backup-dir cho managed upgrade. Không dùng CLI0.2 cũ. Cài không chạy dựng video, không tải dependencies/models hay cần tài khoản Trạm. Giữ nguồn/DNA/config riêng và backup ngoài discovery.
