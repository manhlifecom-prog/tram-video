# codex-video-captions · 0.3.0-beta.7

One local entry, release candidate 0.3.0-beta.7 (internal plan contract 0.3.0-working.1). Publication is pending independent artifact QA; preparation is not a claim of a completed public release. It contains a self-contained generic renderer, meaning-led and optional word captions, animated phone, source-time scenes, integer-frame EDL, person-occlusion adapter and optional licensed sound recipes.
