# One video workflow

Release candidate 0.3.0-beta.1; internal plan contract 0.3.0-working.1. Load this installed SKILL first, then invoke `$codex-video-captions`. Report the selected version/path and missing capabilities before doing media work. Read README.md, references/setup-and-install.md and references/WORKFLOW.md. Never silently fall back to a basic caption starter.

Use the customer's own brief, face, voice, palette, approved reference and music rights. Keep stable semantic phrases as the base when that is the preferred cadence; select word/key motion per meaning, never all-word/all-spring or preset rotation. Optional word motion must visibly move and settle, not just fade. Use each real source-word anchor; keep whole keys on fixed lines. Do not hide first/last words with compound fades.

Map source time through one integer-frame EDL, preserve complete clauses and all necessary negation/conditions. Proposed cuts need actual listening; ASR is an estimate. Build representative stills and motion states for review before a full render. Review the actual encoded MP4 continuously with sound before creative acceptance. Technical hashes/stills/ASR/LUFS are not creative approval.

See references/CAPABILITIES.md for dependencies/limits, references/setup-and-install.md for install, references/MEDIA-RECIPES.md for optional local ASR/matte/audio/image requirements. No provider, paid model, download or publication is authorized by this skill itself.
