# Capability boundary

Included code: meaning-led stable typography, optional anchored word spring/light/burst, data-driven hook/lens, semantic paper/word-chain/type stages, animated phone with source-bound phases/actual RMS, source-time attention camera moves, opaque vignette illustration windows, real-person alpha occlusion over original base, single-offset/multi-range source EDL, fullmix-exclusive audio, exact asset hashes/font checks/cache identity.

Required data: rights-cleared presenter source; exact hash; source-bound word clock; customer profile/colors; explicit cue geometry/anchors and EDL; source OR licensed fullmix; optional real artwork/matte/envelope manifests. Missing/unknown features fail; no fallback to a weaker caption engine. Authoring still requires Codex judgment and human reference/meaning/audio review. A JSON declaration is not evidence of comprehension/listening.

Optional modules are not assets: no ASR model, AI image tool/provider, FFmpeg, browser, customer music or real mask data bundled. Apple Vision yields person occlusion in validated windows over the original source, NOT guaranteed background replacement, hair/prop/fast-hand extraction. Use same-clock CFR RGB and alpha and identical projection; inspect native edges.

Evidence limits: private mechanism production is not this generic package's clean-machine or new-customer test. Generic phone/hook/palette adaptations have static/syntax checks only. No claim of creative parity, Windows compatibility, human listening or owner final approval follows from code copying, valid schemas or a technical render.
