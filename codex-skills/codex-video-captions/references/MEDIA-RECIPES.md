# Optional local preparation

No install/download/model run is automatic. Read [setup and installation](setup-and-install.md) for exact dependencies, offline-ASR requirements/check commands and safe one-entry install/upgrade. Read [audio recipe](audio-recipe.md) for voice/music/SFX routing and rights.

For real person occlusion, use [the complete Swift/CFR/alpha recipe](MATTE-COMMANDS.md). This yields person occlusion over the original fullframe base, not guaranteed background/prop extraction. Review edges and transformed text bounds.

For an optional AI illustration, use an authorized available native image tool with meaning-led prompts, no unnecessary customer upload and explicit output rights/hash. Prefer coherent materials and an intentional opaque vignette if transparent edges fail. The renderer animates supplied assets; it does not generate AI images or silently substitute unrelated filler. No image model/provider or art asset is bundled.
